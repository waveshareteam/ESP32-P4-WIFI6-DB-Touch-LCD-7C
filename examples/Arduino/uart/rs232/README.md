# rs232

## 作用

在 USB 串口和开发板板载 RS232 收发器之间建立双向串口桥接。RS232 端默认使用 `9600 8N1`，引脚为 TX GPIO28、RX GPIO29。

## 使用方法

1. 将外部 RS232 设备连接到开发板的 RS232 接口。
2. 在 Arduino IDE 中选择 `Waveshare ESP32-P4-WIFI6-DB-Touch-LCD-7C`。
3. 打开 `rs232.ino`，编译并上传。
4. 打开串口监视器：USB 端波特率设置为 `115200`，外部设备设置为 `9600 8N1`。
5. 在串口监视器输入的数据会发送到 RS232 设备；RS232 设备收到的数据会显示在串口监视器中。
