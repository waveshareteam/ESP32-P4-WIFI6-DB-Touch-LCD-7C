# rs485

## 作用

在 USB 串口和开发板板载 RS485 收发器之间建立半双工双向串口桥接。RS485 端默认使用 `9600 8N1`，TX GPIO26、RX GPIO27，方向控制 GPIO34。

## 使用方法

1. 将外部 RS485 设备连接到开发板的 RS485 接口。
2. 在 Arduino IDE 中选择 `Waveshare ESP32-P4-WIFI6-DB-Touch-LCD-7C`。
3. 打开 `rs485.ino`，编译并上传。
4. 打开串口监视器：USB 端波特率设置为 `115200`，RS485 设备设置为 `9600 8N1`。
5. 在串口监视器输入的数据会发送到 RS485 总线；收到的数据会显示在串口监视器中。
