# Arduino-ESP32 Local Board Files

[English](README.md) | [简体中文](README_ZH.md)

## Source and Version

The files in this directory come from Arduino-ESP32 `3.3.11`, folder `hardware/espressif/esp32`. Only the board files used by this project are kept:

- `boards.txt`: registers the `Waveshare ESP32-P4-WIFI6-DB Touch LCD 7C` board.
- `variants/waveshare_esp32_p4_wifi6_db_touch_lcd_7c/pins_arduino.h`: defines the GPIO, MIPI-DSI LCD, camera SCCB, touch, audio, SDMMC and ESP-Hosted pins of this board.

The version baseline is Arduino-ESP32 `3.3.11`.
